# Galerie François Benett

Site officiel bilingue de la galerie François Benett, construit avec React et Vite et déployé sur Vercel.

Avant de reprendre le projet, lire [AGENTS.md](./AGENTS.md) puis [docs/PROJECT_HANDOFF.md](./docs/PROJECT_HANDOFF.md).

## Développement local

```text
npm.cmd run dev
```

## Vérification

```text
npm.cmd run lint
npm.cmd run build
```

Site en production : https://www.benett-peintre.fr
